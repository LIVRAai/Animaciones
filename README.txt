TELEACCIÓN · MODELO DE GESTIÓN · VIDEO YOUTUBE

Formato:
- Horizontal 16:9.
- Diseñado para insertarse dentro de un video de YouTube.
- Paleta Teleacción: blanco, negro/gris y naranja.
- Duración aproximada a 1×: 21 segundos.
- Velocidades disponibles: 0.5×, 1×, 1.5×, 2× y 3×.

Concepto explicado:
Un modelo de gestión es el sistema que define cómo se dirige una operación:
objetivos, procesos, indicadores, responsables y mejora continua.

Narrativa:
1. Tener KPIs y personas no garantiza gestión.
2. El modelo organiza cómo se dirige la operación.
3. Conecta objetivo → proceso → indicador → decisión → acción.
4. Permite dejar de gestionar por intuición y sostener resultados.

Controles:
- Reproducir / pausar.
- Flechas para cambiar de bloque.
- Selector de velocidad.
- “Ocultar controles” para grabar limpio.
- Tecla H muestra/oculta controles.
- Barra espaciadora reproduce/pausa.
